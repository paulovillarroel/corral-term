Keyboard shortcuts

Every Corral shortcut, grouped by where you use it. ctrl+b space shows the same list, searchable and with your own keys if you changed any.

How ctrl+b shortcuts work

The shortcuts that work in any pane go through herdr, so they start with its prefix, ctrl+b: press it, let go, then press the next key. They only do something when you use them. If you changed herdr's prefix, Corral's shortcuts use yours.

The palette

ctrl+b space, from any pane, opens Corral's palette: every shortcut and action in one list, grouped by where it works (layouts, any pane, the script editor, the R console, the variables pane, tables and Mirador). Type a few letters to narrow it down, and press Enter to run an action.

Using it

KeyAction
TypeSearch names and keys at once: plot, theme, python, ctrl+r. Accents don't matter. The counter says how many entries match.
↑ ↓, PgUp PgDn, Home EndMove through the list (the mouse wheel too)
EnterRun the selected entry when it's an action: a ↵ next to it says so. The other entries are keys that work in their own place (the editor, a table), listed so you can find them.
BackspaceDelete a letter of the search
EscClear the search; with nothing typed, close the palette

The list is read from your configuration every time it opens, so it shows your own keys after you change them, and actions that have no key yet, like the themes or the language, are one search away. It follows Corral's language too (see Language).

The same list is in the editor (Ctrl+P, then "Corral: keyboard shortcuts") and in any herdr terminal with corral keys. Mirador has its own short list of keys behind ?.

Script editor

The editor, Fresh, uses VS Code's shortcuts. Corral adds the ones below. Some terminals drop keys on their way through herdr (see below), so each action has a key that always arrives and, under "Also", the key you may know from other IDEs, for terminals that send it.

ShortcutAlsoAction
Ctrl+RCtrl+Enter, Alt+EnterRun the selection or, without one, the whole statement under the cursor (including |> or + chains over several lines), and move to the next one
F5Ctrl+Shift+EnterRun the whole file (source(echo = TRUE) in R, %run -i in Python)
Ctrl+LAlt+-Insert <-
Ctrl+UCtrl+Shift+MInsert |>
Ctrl+/Ctrl+Shift+CComment or uncomment
Ctrl+SpaceCompletion (it also appears on its own while you type)
Ctrl+SSave and format (Air in R, Ruff in Python); in the draft, it asks where to save it
Ctrl+PThe editor's command palette (all its actions)
Ctrl+FFind in the file
Ctrl+ZUndo
Ctrl+QClose the editor (the draft is discarded)

Ctrl+L and Ctrl+U do nothing in a .py file.

Plots inside herdr

On terminals that draw images, ctrl+b f shows plots inside herdr instead (see Plots and Mirador). That viewer has three keys: ← → go through the history, o opens Mirador in the browser, and q closes it.

Change a shortcut

$ corral keys --list
$ corral keys --change herdr:toggle shift+e
$ corral keys --change editor:corral_run_line ctrl+e

corral keys opens the palette. --list prints it, with the ID of each shortcut, and --json gives the same list to agents. --change ID KEY gives an action a new key:

  • herdr: IDs are the shortcuts that work in any pane. The key is what comes after ctrl+b (t, shift+k, space) or the whole shortcut ("ctrl+b t"). herdr takes the change at once.
  • editor: IDs are the editor's. The key is the whole shortcut (ctrl+e, f6, ctrl+shift+enter). Close the editor with Ctrl+Q and open it again to use it.
  • The keys of the console, the variables pane, the tables and Mirador are part of Corral and can't be changed this way.

It refuses keys herdr already uses (ctrl+b ? lists them) and keys another shortcut has, unless you add --force, which takes the key from the other shortcut. Claude can read and change your shortcuts if you ask it.

Terminals that drop keys

From Warp, through herdr, only Ctrl plus a letter and the function keys reach the editor intact: Ctrl+Enter arrives as Enter, and shortcuts with Ctrl+Shift or Alt are cut. That is why Corral's main keys are Ctrl+R, F5, Ctrl+L and Ctrl+U.
