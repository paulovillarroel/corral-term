Keyboard shortcuts

Every Corral shortcut and action, grouped as in the palette: first the parts of the IDE, from the layout to the plots, then the agents, the appearance and help. ctrl+b space shows the same list, searchable and with your own keys if you changed any.

How ctrl+b shortcuts work

The shortcuts that work in any pane go through herdr, so they start with its prefix, ctrl+b: press it, let go, then press the next key. They only do something when you use them. If you changed herdr's prefix, Corral's shortcuts use yours.

The palette

ctrl+b space, from any pane, opens Corral's palette: every shortcut and action in one list, grouped by part of the IDE and by what it does. Each entry starts with its category (Layout:, Editor:, Console:, Agents:, Theme:…), so typing a category lists just that. Type a few letters to narrow it down, and press Enter to run an action.

Using it

KeyAction
TypeSearch names, categories and keys at once: agents, theme, python, ctrl+r. Accents don't matter. The counter says how many entries match.
↑ ↓, PgUp PgDn, Home EndMove through the list (the mouse wheel too)
EnterRun the selected entry when it's an action: a ↵ next to it says so. The other entries are keys that work in their own place (the editor, a table), listed so you can find them.
BackspaceDelete a letter of the search
EscClear the search; with nothing typed, close the palette

The list is read from your configuration every time it opens, so it shows your own keys after you change them, and actions that have no key yet, like the themes or the language, are one search away. It follows Corral's language too (see Language).

The same list is in the editor (Ctrl+P, then "Corral: keyboard shortcuts") and in any herdr terminal with corral keys. Mirador has its own short list of keys behind ?.

Script editor

The editor, Fresh, uses VS Code's shortcuts. Corral adds the ones below. Some terminals drop keys on their way through herdr (see below), so each action has a key that always arrives and, under "Also", the key you may know from other IDEs, for terminals that send it.

Change a shortcut

In the palette (ctrl+b space), find the shortcut, press Tab, and press the new key. For the shortcuts that start with ctrl+b, press only the key that goes after it: for ctrl+b u, just u. herdr takes it at once; an editor shortcut, which needs ctrl, alt or an F key, works the next time the editor opens. If the key is herdr's own or another shortcut has it, the palette says so and waits for another one. Backspace puts back Corral's key, and Esc leaves it as it was.

Your keys stay when Corral updates: Corral keeps them in ~/.config/corral/config.json, under keys, and the installer puts them back.

The same from a terminal, also for keys some terminals can't send to the palette, such as ctrl+shift+enter:

$ corral keys --list
$ corral keys --change herdr:toggle shift+e
$ corral keys --change editor:corral_run_line ctrl+e
$ corral keys --reset herdr:toggle

corral keys opens the palette. --list prints it, with the ID of each shortcut, and --json gives the same list to agents. --change ID KEY gives an action a new key, and --reset ID gives it back Corral's:

  • herdr: IDs are the shortcuts that start with ctrl+b and work in any pane. The key is what comes after ctrl+b (t, shift+k, space) or the whole shortcut ("ctrl+b t"). herdr takes the change at once.
  • editor: IDs are the editor's. The key is the whole shortcut (ctrl+e, f6, ctrl+shift+enter). Close the editor with Ctrl+Q and open it again to use it.
  • The keys of the console, the variables pane, the tables and Mirador are part of Corral and can't be changed this way.

It refuses keys herdr already uses (ctrl+b ? lists them) and keys another shortcut has, unless you add --force (from a terminal), which takes the key from the other shortcut. Your agent can read and change your shortcuts if you ask it.

Terminals that drop keys

From Warp, through herdr, only Ctrl plus a letter and the function keys reach the editor intact: Ctrl+Enter arrives as Enter, and shortcuts with Ctrl+Shift or Alt are cut. That is why Corral's main keys are Ctrl+R, F5, Ctrl+L and Ctrl+U.
