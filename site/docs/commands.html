Commands

Every corral command, with its options. corral --help lists them, and corral COMMAND --help (or -h) prints a command's usage without running it.

Corral's messages are in English or Spanish (corral config language); commands and options keep their English names in both.

Workspace

corral

Typed alone in a terminal, it opens the workspace for the folder you are in. In a herdr pane it runs corral layout there, like ctrl+b a. In any other terminal it opens herdr with it: it starts herdr's server if none is running, goes back to the workspace whose layout already runs in that folder or creates one, and that terminal becomes herdr. When an agent runs it, without a terminal, it shows the list of commands.

corral layout

Opens the workspace in a new tab: the agent, the script, the console and the variables (ctrl+b a; with --focus code, ctrl+b shift+s). A new layout also opens a tab named terminal behind it, with a shell in the project folder, once per workspace (corral config terminal_tab off leaves it out). If this workspace already has a layout, it rearranges that one instead, to the focus you ask for, and keeps its console, draft and agent; the other options apply only to a new layout, except --lang, which switches the console.

OptionWhat it does
--focus agent|code|notebookFocused on the agent (the default); on the code, with the script on the left and the agent over the console; or the notebook, with the script over the console on the left and the agent over the variables on the right
--lang r|pythonThe console it starts with, and the language of the draft (corral config start, else R)
--shellAdds a shell next to the variables
--ratio NWidth of the left column, as a fraction (the one you left in that layout; else 0.516 for the agent first, 0.62 for code first and the notebook)
--default-sizesForgets the pane sizes you left in every layout and gives the open one Corral's; it opens nothing
--agent COMMANDThe agent's command (CORRAL_AGENT, then corral config agent, else the first installed of claude, codex, gemini and opencode); '' leaves a shell
--editor COMMANDThe editor (fresh, or CORRAL_EDITOR); '' leaves out the script
--console COMMANDThe console's command (for R, CORRAL_R; else corral _console r or corral _console python)
--cwd FOLDERThe folder to open it in (the pane's current folder)
--label NAMEThe tab's name (corral)

corral close

Closes Corral's panes in the tab (script, console, variables, the shell from --shell, and the ones in the hidden tab) (ctrl+b shift+q). The agent the layout started closes too when herdr says it is idle, and the terminal tab it opened when nothing runs there; an agent at work, one waiting for you, or a command running stays, and it says so. Panes you added yourself stay. Then it takes you back to the tab you opened Corral from, if it is still there. The R session closes with its pane, and the unsaved draft is discarded.

corral toggle

$ corral toggle script

Expands the script or the console, or shows both again (ctrl+b t). It takes script, console or both, and agent instead of script in the layout focused on the code. Without an argument, it expands the pane you are in, or goes back to both.

corral switch

$ corral switch python

The layout's console switches to r or python; without an argument, to the other one (ctrl+b y). The first time, it starts Python. The other console keeps running in the "corral (hidden)" tab.

corral script

Adds the editor over the console in an existing layout, with a new draft or the file you name. With one of these options, it works on the workspace's draft instead:

OptionWhat it does
--readPrints the current draft, including what you haven't saved
--save PATHSaves the draft to that file; --force replaces an existing one
--write [FILE]Adds the text from stdin (or from the file) at the end of the draft, as one edit that Ctrl+Z undoes; --replace replaces everything
--editor COMMANDThe editor to add (fresh, or CORRAL_EDITOR)

corral console

Marks the current pane as the R or Python console, by what runs in it, and switches Corral on if R or IPython is open there (ctrl+b m). --lang r|python sets the language and --pane PANE marks another pane.

corral versions

The R version (from rig) or Python version (from uv) the consoles run. Without a version, it opens a window with the installed ones; the palette has it as "Console: R version (rig)" and "Console: Python version (uv)". See Choose the R or Python version.

OptionWhat it does
r|pythonWhich console
VERSIONUses that version (4.5.2, 3.13); default goes back to rig's or uv's default
--list, --jsonThe installed versions, for people or for agents, with the one in use marked
--restartRestarts that console so it runs the version now; its objects are lost

corral keys

The shortcut palette (ctrl+b space).

OptionWhat it does
--listPrints every shortcut, with its ID
--jsonThe same list as JSON, for agents
--change ID KEYChanges a herdr shortcut (corral keys --change herdr:toggle shift+e) or an editor one (editor:corral_run_line ctrl+e); it refuses keys already in use unless you add --force. Corral remembers it, so it stays when Corral updates. In the palette: Tab on the shortcut
--reset IDGives the shortcut back Corral's key (in the palette: Tab, then Backspace)

Code and data

corral send

$ corral send 'summary(mtcars)'

Sends code to the console in view, bringing it into view (and starting it) if needed; this is what Ctrl+R, F5 and ctrl+b enter run. Without code in the arguments, it reads stdin or herdr's selection.

OptionWhat it does
--lang r|python|sqlSend to that console instead of the one in view; sql runs the code as SQL in the console in view (SQL)
--sourceRun the code as a file: source() in R, %run -i in Python
--name FILEThe file's name, shown with --source
--clipboardRead the clipboard when there is nothing else to send (from a herdr shortcut, it always does)

corral eval

$ corral eval 'summary(mtcars)'

Runs code in your console and prints the output, for agents. R by default.

OptionWhat it does
--lang r|python|sqlThe console to use; sql runs SQL in the console in view
--file FILERun a file
--timeout SSeconds to wait for the result (300)
--wait-idle SSeconds to wait for a busy console (20)
--max-chars NLongest output before it is cut (20000)
--checkOnly check that the console is there and print it as JSON
--replaceIts plots replace the ones from the previous request

Working with agents explains the output and the exit codes.

corral audit

$ corral audit
$ corral audit --last 100 --json

What agents asked to run in your consoles, newest last: when, the outcome (ok, error, timeout, refused, blocked, not approved, not run), the language, the agent's pane and the code. --json prints the log's lines as they are. It shows the last 20 requests; --last N shows more. See the Security model.

corral vars

The variables of the console in view, over the terminal (ctrl+b d).

OptionWhat it does
--jsonPrints them as JSON, for agents; --lang r|python picks the console
--splitAdds the permanent variables pane under the R console
--paneRuns as the permanent pane (what the layout's variables pane runs)
--inlineShows them in the current terminal instead of a popup

corral view

$ corral view data/sales.parquet

Opens a table (parquet, CSV, JSON) in the table viewer. --title TITLE sets its title, --mirador opens it in Mirador instead, --inline shows it in the current terminal instead of a popup, and --session SESSION ties it to a session in Mirador.

corral plots

The latest plot, in Mirador (ctrl+b f); on a terminal that draws images, in a herdr popup. --inline shows the in-terminal viewer in the current terminal.

corral mirador

Mirador, the view in the browser. Without options, it starts the server if needed and opens a window if none is open.

OptionWhat it does
--openOpens a window even if one is open
--urlPrints the address
--stopStops the server
--foregroundRuns the server in this terminal

corral open

$ corral open http://localhost:8080

Opens a local URL in the browser; this is what Ctrl+click on a local address in herdr runs. Without a URL, it opens Mirador.

Installation and settings

corral config

$ corral config r_console r

Reads or changes the settings: corral config prints them all, corral config KEY one, and corral config KEY VALUE sets it. Configuration lists every key.

corral theme

Applies herdr's theme to the editor, the viewers, VisiData and Mirador now. --show only prints the palette.

corral ark

Shows whether the R console uses Ark and what is installed. --install [VERSION] downloads Ark (0.1.252 by default, the tested version).

corral doctor

Checks the dependencies, the herdr plugin, the theme, Mirador, the browser, and which terminal it detects, one line each.

corral install

Checks the requirements and repairs the installation, without downloading Corral. In a terminal, it offers to install herdr and the R package jsonlite when they are missing, to update herdr when it is too old, and to put ~/.local/bin on the PATH; httpgd it installs by itself, and if it can't, Corral works without R's plots in Mirador. --check only checks.

corral update

Installs the latest published version when it is newer than yours, with the same install line as the first time: it checks the package's SHA-256 and its build provenance. --check only says whether there is a newer one. A Corral installed from a copy of the repository isn't replaced: it says to git pull there and run sh install.sh again. In the palette: "Update: install the latest version of Corral", in a popup that waits for Enter. Consoles already open keep the version they started with.

corral uninstall

Removes Corral from herdr, R, the editor and your agents (the skill for Claude Code, Codex, Gemini CLI and opencode). Your settings and sessions stay. See Install.

corral --version

Prints the version and the folder the binary comes from. corral --help (or corral help) lists the commands.

Internal commands

Corral's panes and the editor run these. You don't need to call them, but they show up in process lists and on the Performance page.

CommandWhat it is
corral _console r|pythonWhat a console pane runs: Ark, plain R or IPython, according to your settings
corral _lsp r|python|ruffThe editor's language servers: the bridge to Ark's (or languageserver with plain R), ty (or pylsp), and Ruff
corral _miradorMirador's server
corral _table FILEThe table viewer in its popup (--bench times its queries, for Performance)
corral _vars, _plots, _keys, _versions, _approve, _updateThe popups: variables, plots, the palette, the versions window, an agent's request, the update
corral _editor, _show-object, _plot-readyThe script pane, an object opened from the variables, and the note R and Python leave when a plot is ready
corral _update-checkThe daily check for a new version, in the background
