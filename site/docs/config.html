Configuration

Corral's settings live in ~/.config/corral/config.json, and corral config reads and changes them. A few environment variables and R options cover the rest.

corral config

$ corral config
$ corral config r_console
$ corral config r_console r

Without arguments it prints every setting as JSON. With a key, it prints that value; with a key and a value, it sets it. The keys with a fixed list of values refuse anything else and tell you what they take.

Language

Corral speaks English. To see its windows, messages and Mirador in Spanish:

$ corral config language es
$ corral config language en

Or pick "Idioma: español" or "Language: English" in the palette (ctrl+b space). Open windows and consoles switch within a couple of seconds; the script editor, the next time it opens. The editor (Fresh) follows Corral's language whatever your system's is; to give it another one, add --locale to CORRAL_EDITOR, for example fresh --locale fr. Commands, options and settings keep their English names in both languages.

Set by Corral

Corral sets these itself, for its own processes. You rarely need them, but you may see them:

VariableWhat it is
CORRAL1 in the consoles Corral starts. It is what switches Corral on in R (CORRAL=1 R does it by hand).
CORRAL_SESSIONThe id of the session a command should use.
CORRAL_REQUESTThe agent's request an approval or review popup shows.

R options

Set them in your .Rprofile.

OptionEffect
options(corral.viewer = "mirador")The first plot opens Mirador inside herdr too. "httpgd" opens httpgd's own viewer.
options(corral.open_plots = FALSE)The first plot doesn't notify or open anything.
options(corral.httpgd = FALSE)Keeps R's default graphics device.
options(corral.vars = FALSE)Doesn't publish the variables, and turns off Corral's work after each command with them: no checkpoints, and Mirador and the plot watcher aren't told about new plots.
options(corral.always = TRUE)Switches Corral on in every R session you open. It goes before Corral's line in .Rprofile.
options(corral.bin = "/path/to/corral")The corral command R calls, instead of the one on the PATH.
