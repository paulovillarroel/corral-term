Themes

herdr's theme rules. Corral reads it and dresses everything else to match: the editor, the console prompt, the variables pane, the viewers, VisiData and Mirador. When you change the theme in herdr, Corral follows within seconds.

How Corral follows herdr

Corral reads the theme from ~/.config/herdr/config.toml ([theme] name and the colors in [theme.custom]) and applies it:

  • Fresh uses the corral theme (~/.config/fresh/themes/corral.json), with the terminal's background, so the editor looks like the other panes.
  • The R console's prompt, the variables pane and the viewers use the theme's accent and grays.
  • VisiData takes the same colors, approximated to the terminal's 256-color palette.
  • Mirador gets the palette as CSS variables.

Changes are followed live. If you change herdr's theme, or its colors in config.toml, the editor, the variables pane and Mirador recolor on their own within a few seconds, without restarting anything. VisiData takes the new colors the next time you open a table.

$ corral theme
$ corral theme --show

corral theme forces the update. --show only prints the palette in use.

Built-in palettes

herdr doesn't publish the values of its colors, so Corral uses the published colors of each theme: vesper, catppuccin, dracula, tokyo-night, nord, gruvbox, one-dark, solarized, kanagawa and rose-pine, plus your settings in [theme.custom].

A variant Corral doesn't know, such as a light one, uses its dark sibling's palette, or catppuccin (herdr's default) if there is none.

Your own colors

Colors you set in herdr's [theme.custom] override the base palette in Corral too. Corral reads these tokens, each as a #rrggbb color: accent, panel_bg, sidebar_bg, surface_dim, active_row_bg, selection_bg, text, green, yellow, red, mauve and peach.

[theme]
name = "tokyo-night"

[theme.custom]
accent = "#ff9e64"

Corral's own theme: Dark 2026

herdr doesn't let you install themes, but Corral brings its own, with exact interface and syntax colors. For now there is one, dark-2026: VS Code's new dark theme, Dark 2026.

$ corral config theme dark-2026
$ corral config theme herdr

The first dresses the editor, the console, the variables and Mirador. The second goes back to following herdr's theme.

You can also pick it from the palette (ctrl+b space): type theme and choose "Theme: Dark 2026 (VS Code's and Positron's)" or "Theme: back to herdr's". A herdr notice confirms the change.

What it does to herdr

corral config theme dark-2026 dresses Corral and herdr at once: it adds a [theme.custom] with the theme's colors to ~/.config/herdr/config.toml, marked with a Corral comment. Before writing, Corral asks herdr to check the new configuration, and leaves the file as it was if herdr wouldn't accept it.

It works like any other theme. If you later choose another one in herdr (ctrl+b s), Corral notices, removes those colors from herdr's configuration and goes back to following herdr's theme.

If you already have colors of your own in [theme.custom], Corral doesn't touch them, and the theme applies to Corral only.

Terminal background

The background of the panes comes from your terminal, Warp for example. Dark 2026's backgrounds are #121314 and #191a1b: set one of them as Warp's background and every pane matches.
