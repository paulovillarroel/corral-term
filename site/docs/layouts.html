Layouts and panes

A Corral layout puts the agent, the script, the console and the variables in one herdr tab. There are three arrangements, and you can expand or swap panes without losing anything, because every session keeps running in its herdr pane.

The panes

PaneWhat it holdsKeys
AgentYour agent: the one in corral config agent, or else the first installed of Claude Code, Codex, Gemini CLI and opencode. You talk to it here; it runs its code in your console with corral eval.
Script corral:scriptThe editor, Fresh, with an empty draft ready to use: draft.R, or draft.py when Corral starts with Python. Switching the console to the other language opens that language's draft in another tab. If you don't save them, they are deleted when you close Corral (The draft).Ctrl+R line or selection, F5 the file, Ctrl+S save
Console corral:r, corral:pythonThe live session you and the agent share: R on Ark (or plain R), or Python in IPython.ctrl+b y switches R and Python
Variables corral:varsThe objects in the session, in tabs: Data, Plots, Values, Functions and Other. Enter shows one: a data frame opens in the table viewer.ctrl+b d a bigger view
Shell corral:shellOnly with corral layout --shell: a shell next to the variables.

ctrl+b t expands the script or the console over the space they share, and brings both back (below). Some things open over the panes instead of in one: the table viewer (View()), the plots, and the popup where you approve an agent's request. Mirador, with every plot and table, opens in your browser (ctrl+b f).

The three layouts

WhereFocused on the agent (ctrl+b a)Focused on the code (ctrl+b shift+s)Notebook (palette)
Left (52 % of the width, 62 % with the script)AgentScriptScript, over the console
Right, topScriptAgentAgent

On the right, the two upper panes share 73 % of the height, 57/43, and the variables take the other 27 %. The editor opens with the file explorer in view, 31 columns wide in every layout; if you set your own file_explorer.width in Fresh's configuration, Corral keeps it.

A new layout also opens a tab named terminal behind it, with a shell in the project folder, one per workspace; corral config terminal_tab off (palette: "Layout: no terminal tab") leaves it out.

ctrl+b a is the default: the agent gets the big pane. Use ctrl+b shift+s when you spend more time in the code; it needs the editor (Fresh). Notebook puts the script over the console on the left, like RStudio or Positron, and the agent over the variables on the right; it also needs the editor. It has no key of its own: it's "Layout: notebook" in the palette, and Tab there gives it one. The first layout you open goes in a new tab. Once it's open, the others rearrange it in place: the agent and the script swap sides, or the console moves under the script, and the console, its objects, the draft and the agent's conversation stay as they are. Only closing Corral (ctrl+b shift+q) ends them. The left column starts at about half the width when the agent is there, and at 62 % when the script is, since code needs the long lines. If you resize panes by hand, each layout keeps your sizes: Corral notes them when you switch layouts, press ctrl+b t or close Corral, and that layout opens with them again, in any workspace. "Layout: back to Corral's sizes" in the palette forgets them. All three are in the palette (ctrl+b space), in the «Layouts and panes» group.

From the command line

$ corral layout
$ corral layout --focus code
$ corral layout --focus notebook
$ corral layout --shell
$ corral layout --ratio 0.6
$ corral layout --lang python

--focus code opens the layout focused on the code, and --focus notebook the notebook. --lang python starts it with the Python console and a Python draft instead of R; to make that the rule, use corral config start python, or "Layout: start with Python" in the palette. --shell adds a shell next to the variables. --ratio changes the width of the left column (the one you left in that layout, else 0.516 for the agent first and 0.62 for the other two). --default-sizes forgets the sizes you left and gives the open layout Corral's. --editor '' leaves out the script and --agent '' leaves a shell where the agent would be. Commands has the rest of the options.

Another agent

The agent pane runs the first agent installed of Claude Code, Codex, Gemini CLI and opencode. To run another one there every time, set its command:

$ corral config agent codex

--agent and the CORRAL_AGENT variable win over this setting.

Expand the script or the console

ctrl+b t expands the pane you are in (the script or the console) to the whole area they share, above the variables. In the layout focused on the code, it expands the agent or the console; in the notebook, the script or the console, in the left column. ctrl+b t again brings both back, with the same proportion as before.

herdr doesn't shrink a pane below 10 %, so the pane that makes room moves to a tab of its own, "corral (hidden)", where it keeps running. Ctrl+R and the agent keep running code in the console even while you can't see it.

$ corral toggle script
$ corral toggle console
$ corral toggle both

From the command line, say what you want to see: script, console or both. In the layout focused on the code, use agent instead of script. Without an argument, corral toggle does what the shortcut does.

Switch between R and Python

ctrl+b y switches the console spot between R and Python. The first time, it starts Python. The console you are not using waits in the hidden tab and keeps its variables; if you go to that tab, you can use it there as well.

$ corral switch python
$ corral switch r

Running code switches too: Ctrl+R or F5 in a .py file brings the Python console, and in a .R file, the R one. The variables pane, Mirador and View() follow the console in view. Consoles has the details.

The hidden tab

Each workspace has at most one hidden tab, named "corral (hidden)". It holds the pane that ctrl+b t moved out of the way and the console of the language you are not using. Everything there keeps running, and Corral brings each pane back to its place when you need it.

Close Corral

ctrl+b shift+q (corral close) closes the script, the console and the variables, including the panes in the hidden tab. It closes the agent too when it is idle (claude --continue picks the conversation up again) and the terminal tab when nothing runs there, and takes you back to the tab you opened Corral from. An agent at work or waiting for you, or a command still running, stays, and the message says so. Closing the console ends that R session, and the unsaved draft is discarded. Mirador stays open until you close its window; corral mirador --stop stops its server.

Add panes to a layout you already have

If you set up your own tab and marked a pane as the R console (ctrl+b m), you can add the other panes to it:

$ corral script
$ corral vars --split

corral script adds the editor over the console in view, R or Python, with a new draft in that language or with the file you name. corral vars --split adds the variables pane under the R console, so it needs an R console in the workspace.

Corral finds its panes by their herdr labels: corral:script, corral:r, corral:python, corral:vars and corral:shell. A workspace has one of each; a new layout takes the labels away from older panes.

Sessions live in herdr panes

Everything with state lives in a herdr pane: the R and Python sessions and the agents. The viewers (the variables window, tables, Mirador) read from those sessions each time they open, so you can close them at any time and lose nothing. Closing the terminal window loses nothing either, because herdr keeps the panes running.

If the herdr server itself stops (a Windows restart, wsl --shutdown), the R and Python sessions end. herdr restores the panes, and with checkpoints on, the next console in the project gets the objects back (Consoles).

When Corral acts

Corral changes nothing until you ask:

  • In R, it only switches on in the console a layout opens (which starts R with CORRAL=1), or in an R where you turn it on: ctrl+b m in that pane, or corral_activate() in the console. Any other R works as always, with its own View() and graphics device, and Corral never switches on inside RStudio or Positron. To switch it on in every R, add options(corral.always = TRUE) to your .Rprofile, before Corral's line.
  • The layout (script, console and variables) only appears with ctrl+b a or ctrl+b shift+s.
  • The ctrl+b shortcuts only do something when you use them.
  • Agents use your console only if the workspace has an active Corral console. Otherwise, they work as usual.
