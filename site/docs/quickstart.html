Quick start

A short tour, from opening the layout to closing it. It takes about two minutes. You need Corral installed; on Windows, inside WSL (step by step).

Open the layout

In a terminal, go to a project folder. Corral's shortcuts start with ctrl+b: press it, let go, then press the next key.

Type corral and press Enter. herdr opens with Claude Code on the left and, on the right, the script editor over the R console, with the variables pane below them. Next to it, a tab named terminal has a shell in the same folder. Inside herdr, corral or ctrl+b a open the same layout in a new tab.

Prefer the code in the big pane? ctrl+b shift+s opens the same panes with the script on the left and Claude over the console. Layouts and panes has both.

Write and run code

The editor opens an empty draft, ready to use. It is temporary: if you don't save it (Ctrl+S), it is deleted when you close Corral. Type a couple of lines:

cars_df <- mtcars
summary(cars_df$mpg)

Put the cursor on the first line and press Ctrl+R. Corral runs the whole statement under the cursor, even when it spans several lines, and moves to the next one. Press it again for summary(). F5 runs the whole file.

Two more keys you will use often: Ctrl+L inserts <- and Ctrl+U inserts |>. Completion appears while you type. Write cars_df$ and it offers the columns of your cars_df, because the language server is the same R as your console.

See your variables

The variables pane under the console now lists cars_df. It updates after every command, yours or the agent's. Its tabs sort your objects into data, plots, values, functions and other; ← → or the keys 1 to 5 move between them.

Open a table

Run this in the editor or type it in the console:

View(cars_df)

The table opens over the terminal. s sorts by the current column, f filters with a condition such as mpg > 20 & cyl == 6, and i shows a summary of each column. q closes it. Enter on a data frame in the variables pane opens it the same way.

Draw a plot

plot(cars_df$wt, cars_df$mpg)

The first plot of a session opens Mirador, a light page in your browser. Later plots appear there about 80 ms after they are drawn, without taking your focus. ← → go through the history, and c copies the plot as an image. Back in herdr, ctrl+b f brings Mirador to the front at the latest plot.

Switch to Python

Press ctrl+b y. The console spot now shows Python: IPython inside your project's uv environment. The first time, uv prepares the environment, which can take a few seconds. Your R console keeps running in a hidden tab, with all its objects, and ctrl+b y again brings it back.

You rarely need to switch by hand: Ctrl+R or F5 in a .py file brings the Python console, and in a .R file, the R one. Python needs uv.

Ask the agent

Go to the Claude Code pane and ask for something that needs your data, for example: "fit a linear model of mpg on wt with cars_df and plot the residuals". With Corral's skill, Claude runs its code in your console with corral eval. You see each command appear there, and the model and the plot stay in your session, where you can keep working with them.

Close

ctrl+b shift+q closes the script, the console and the variables, leaves Claude running as a normal herdr pane in its tab, and takes you back to the tab you opened Corral from. Closing the console ends that R session. The draft is discarded, so press Ctrl+S first if you want to keep it: in the draft, it asks for a name and saves the file in your project.

Mirador stays open until you close its window.
