R and Python · in your terminal

An agentic Data Science IDE that opens in milliseconds.

Corral is an IDE that lives in your terminal, built with modern technology around the data science workflow: write, run, explore your data, plot. For R and Python, blazing fast with massive data, ready for professional work and ready to run with your agents.

curl -LsSf https://raw.githubusercontent.com/paulovillarroel/corral-term/main/install.sh | sh

Checks everything first, changes nothing until it's all there, never uses sudo.

Run it in your WSL terminal (Ubuntu). macOS isn't supported yet.

01

Rust, end to end.

Corral is one small Rust binary with no dependencies: the layout, the consoles, the variables pane, the table viewer, the shortcut palette, Mirador's server and the installer. The engines it drives are Rust too: herdr, Fresh, Ark, Air, Ruff, ty and uv. That's why a whole workspace, editor and language server included, is ready in about 400 milliseconds.

03

Big tables, instantly. DuckDB under the hood.

View(df) saves the table as Parquet, and Corral asks DuckDB only for what's on screen: a page of rows, the count, a sort, a search, a filter in R or SQL, a summary of every column. Each takes milliseconds. Ten million rows show up in about 34 ms, and the viewer uses about 3 MB. Press m to send the table to Mirador when you want the browser, and the variables pane keeps every object in view as you work.

Built for working with agents.

Any agent (Claude Code, Codex, Gemini, opencode…) runs R and Python in your console with corral eval and gets back what it printed, plots included. FAQquestions

Questions people ask.

Which agents does it work with?

Any agent that can run shell commands: Claude Code, Codex, Gemini CLI, opencode and others. They run code in your console with corral eval, and Corral's skill follows the open Agent Skills standard, so the installer puts it where they look for it (~/.agents/skills, and ~/.claude/skills for Claude Code).

Does it replace Positron, RStudio or VS Code?

No. Positron, RStudio, VS Code and its forks (Cursor, Windsurf…) are still the right tools for heavier work, and Corral doesn't touch them. Corral is for working with agents on your data without losing control of the data or the code: the agent runs its code in your console, where you watch every line, and what it creates stays in your session, in plain sight.

None of them has to be installed: Corral runs R on Ark, the kernel Positron uses, on its own, and the installer downloads it.

Is Python as complete as R?

Both get the whole workbench: the editor, the console, the variables pane, View(), plots in Mirador and agents. R is the default console, and its language server knows your live objects. Python runs in IPython inside your project's uv environment, with ty and Ruff in the editor.

How big can my data be?

Looking at it scales: View() hands the table to DuckDB, which reads only what's on screen, so ten million rows show up in about 34 ms. Computing is up to your code, as in any IDE: data frames live in memory, while arrow, duckdb, polars or data.table let you go further.

Does it run on macOS or Windows?

On Linux, and on Windows through WSL. macOS isn't supported yet.

Does my data leave my machine?

Corral runs everything locally. Mirador listens only on 127.0.0.1, behind a token. Your agent talks to its own provider as it always does; Corral sends nothing anywhere.

Can I use it in Spanish?

Yes. Corral speaks English by default; corral config language es, or "Corral: idioma: español" in the palette, switches its windows, messages and Mirador to Spanish. Commands stay in English.

How do I remove it?

corral uninstall takes out everything the installer added, from herdr, R, the editor and your agents. The copies of the files it changed stay, in case you want them.
